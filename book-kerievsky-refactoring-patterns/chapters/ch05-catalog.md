# 第5章 模式导向的重构目录

> 来源：《重构与模式》（Joshua Kerievsky, *Refactoring to Patterns*）中文版第5章（OCR 行 2084–2272）。忠实压缩，OCR 错字已按上下文修正。

## 5.1 重构的格式

本书所有重构的格式基本沿用 Martin Fowler《重构》一书，并做了少量改进。每个重构通常包括：

- **名称（Name）**：形成重构统一语汇的重要部分；既包含《重构》中的重构，也包含本书新定义的重构。
- **概要（Summary）**：用文字 + UML 简图（sketch）描述一种设计转换。简图使用类图、对象图、协作图、序列图等，但不给出类的全部方法/字段，只突出转换的本质；灰色方框标注重构的关键参与者（通常来自"做法"一节中的类或方法名）。
- **动机（Motivation）**：说明为什么使用该重构，可能含对模式的高层概述；结尾附"优点与缺点"方框（+ 表示优点，- 表示缺点）。模式细节请参阅专门图书。
- **做法（Mechanics）**：按编号步骤列出实现指导，可含引言说明重构前的准备；编号步骤与示例一节一一对应。做法引用了大量《重构》中的基础重构，建议参阅原书。做法是"从一个设计转换到另一个设计的安全方式"，不是唯一方式；可部分遵循，设计已足够改善即可停手。
- **示例（Example）**：深入演示如何用该重构转换设计，步骤编号与做法对应；粗体代码表示新增修改，删除线表示删除。
- **变体（Variations）**：部分重构含变体一节，不求穷尽，但涵盖重要变体。

## 5.2 本目录中引用的项目

示例一部分来自真实项目、一部分受真实项目启发（实战代码的重构决策受代码各种因素限制，教学价值高于纯演示代码 toy code）。多次被引用的项目：

### 5.2.1 XML Builder
作者多年编写各种创建 XML 的代码：XMLBuilder、DOMBuilder、TagBuilder、TagNode。TagBuilder 是作者最喜欢的 XML 创建程序。相关重构示例：
- 用 Composite 替换隐含树（7.5）
- 用 Factory Method 引入多态创建（6.4）
- 用 Builder 封装 Composite（6.5）
- 将聚集操作搬移到 Collecting Parameter（10.1）
- 通过 Adapter 统一接口（8.5）

### 5.2.2 HTML Parser
SourceForge 上的开源 HTML 解析库（http://sourceforge.net/projects/htmlparser），由 Somik Raha 发起；作者加入后（常与 Somik 结对）改进设计，产生许多重构。相关重构示例：
- 将装饰功能搬移到 Decorator（7.3）
- 将创建知识搬移到 Factory（6.2）
- 提取 Composite（8.2）
- 将聚集操作搬移到 Visitor（10.2）

### 5.2.3 贷款风险计算程序
作者早年在华尔街银行开发贷款/市场/全球风险估算程序（Turbo Pascal、C++），本书示例为受其启发的改写版本。相关重构示例：
- 链构造函数（Chain Constructors, 11.1）
- 用 Creation Method 替换构造函数（6.1）
- 用 Strategy 替换条件逻辑（7.2）

## 5.3 起点

引 Fowler：重构仅仅是一个起点，不完美但有用，读者可在此基础上不断提高重构能力。本书重构亦然——随着工具和 OO 语言的发展，重构方式越来越多；最好将其作为**因地制宜的指导原则**：可跳过某些步骤、可换一种方式，最终标准是是否改善了设计。目录共 27 个重构，未囊括所有模式导向的重构，欢迎其他作者扩充。
