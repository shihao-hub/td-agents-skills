# sh-transcript-reader — 访谈转写稿与字幕转杂志风精读本

把碎片化的语音转写稿（`.srt` / `.txt`）或长视频访谈，转化为一份**高品质、去 AI 味、报刊出版物级、自解释语义命名的独立 HTML 沉浸式阅读单页**。

---

## 一、核心铁律：HTML 严谨语义命名规范（杜绝随意命名）

> ⚠️ **用户硬性红线**：HTML 文件名代表沉浸阅读资产，**严禁使用任何随意或临时哈希命名**！

### 1. 命名禁止项（Anti-Patterns）
- ❌ **严禁使用平台散列 ID 或视频哈希**：如 `douyin_7699461776018132258_reader.html`、`BV1xx411c7xx.html`；
- ❌ **严禁使用临时/默认空泛词**：如 `reader.html`、`output.html`、`test.html`、`temp_reader.html`；
- ❌ **严禁包含 Windows 非法文件字符**：如 `/ \ : * ? " < > |`；
- ❌ **严禁无意义的纯数字或机械后缀**：如 `12345.html`、`final_v2_new.html`。

### 2. 规范命名范式（Semantic Naming Formula）
所有生成的精读 HTML 文件必须遵循以下公式：

```text
标准格式：{清洗后真实标题}_精读本.html
多期系列：{YYYY-MM-DD}_{清洗后标题}_精读本.html
```

- **清洗规则**：
  1. 提取访谈的真实主标题（如《北大卷王，重新思考内卷与创造力》）；
  2. 符号安全映射：`|` 替换为 ` - `；`:` 替换为全角 `：`；`?` 替换为全角 `？`；`/` 与 `\` 替换为 `-`；引号一律剔除；
  3. 合并连续空白，标题长度安全截断在 50~60 字符内，结尾统一附带 `_精读本.html`；
  4. 最终范例：`北大卷王，重新思考内卷与创造力 - 钦文对话马兆远_精读本.html` 或 `北大卷王，重新思考内卷与创造力_精读本.html`。

## 二、双模态排版架构（Dialogue vs Monologue）

引擎具备智能上下文感知能力，支持自动识别或手动指定排版形态：

| 模态类型 | 适用内容场景 | 排版视觉表现 |
| :--- | :--- | :--- |
| **`dialogue` 访谈对话模式** | 双人播客、圆桌对谈、主持人问答 | 发言人徽章色彩绑定（松针绿嘉宾 vs 陶土赭石主持）、问答段落交替、时间戳对齐与双人发言人筛选器 |
| **`monologue` 演说论述模式** | 单人演讲、思想漫笔、劝学、口播、讲座 | **绝不出现生硬的假问答气泡**；自动归拢为思想流论述章节（Essay Sections）、论点小标题、连贯正文大段落与哲思金句拉花（Pull-quotes） |

## 三、去 AI 味设计与排版规范（对齐 sh-frontend-deai）

生成的 HTML 单页严格遵循以下视觉基线：

1. **色彩哲学**：
   - **基底**：纸面柔和暖白 `#FBFBFA`（避免刺眼纯白，杜绝暗黑赛博终端风）；
   - **正文字体**：深邃松烟墨黑 `#1C221E`（避免粗糙纯黑 `#000`）；
   - **发言人语义绑定**：
     - 主讲嘉宾：学者松针深绿 `#1A4432` / 浅绿底 `#EBF3EE`；
     - 主持人/提问者：陶土赭石 `#8E4A28` / 暖褐底 `#FBF2EC`；
     - 重点引言：暖赭色 `#E68A36` 竖边强调；
   - **绝对禁止**：Tailwind 默认蓝紫渐变（`#6366F1` / `#8B5CF6`）、霓虹发光文字、无意义 emoji 装饰。
2. **文本版式**：
   - 标题：宋体/思源宋体衬线（`"Songti SC"`, `"Source Han Serif SC"`）；
   - 正文：舒适屏显无衬线体，阅读柱宽度受控在 `780px` 内，行高 `1.88`；
   - 关键金句提取为杂志大引言卡（Pull-quotes）。
3. **内容架构**：
   - **顶置导读面板**：4 组核心心智模型对比（如「赛道思维 vs 花园思维」）；
   - **分幕式章节（Thematic Acts）**：将零散字幕按逻辑演进划分为 5~7 个主题大幕；
   - **交互辅助**：滚动阅读进度条、视图筛选器（全部实录 / 仅看嘉宾 / 仅看主持）、字号切换（标准 / 大字）、一键纯净打印样式。

## 三、标准执行 SOP

### 步骤 1：前置检查与输入获取
- **输入物**：已有 `.srt` 字幕文件、`.txt` 转写稿，或由 `sh-video-transcribe` / `sh-zhangshihao-douyin-dl` 刚生成的媒体及产物；
- **元信息提取**：确认访谈主标题、主讲嘉宾名、主持人名与时长。

### 步骤 2：自动渲染生成（单命令驱动）
使用本技能自带的脚本渲染引擎：

```powershell
# 脚本路径：
# D:\Users\language_projects\.agents\skills\sh-user-skills\sh-transcript-reader\scripts\render_reader.py

uv run "D:\Users\language_projects\.agents\skills\sh-user-skills\sh-transcript-reader\scripts\render_reader.py" `
  "<输入SRT或TXT文件路径>" `
  --title "<访谈真实标题>" `
  --guest "<嘉宾姓名>" `
  --host "<主持姓名>"
```

- 若未指定 `--title`，脚本将自动根据同名 summary 笔记或文件名提取；
- 脚本自动调用 OpenCC 将繁体字幕转为纯正简体中文，并自动修正常见 ASR 同音错字；
- 产物自动落在与媒体同目录下的 `{清洗后真实标题}_精读本.html`。

### 步骤 3：验收检查清单
- [ ] **文件名自检**：文件名是否严谨自解释（如 `北大卷王，重新思考内卷与创造力_精读本.html`），绝无 `douyin_*_reader.html` 等散列残渣；
- [ ] **编码检查**：文件头 3 字节绝无 BOM（`EF BB BF`），全篇纯正简体中文 UTF-8；
- [ ] **视觉检查**：打开浏览器确认排版是否具备人文纸面质感，筛选器与字号切换功能正常；
- [ ] **交付汇报**：给用户提供标准可点击的本地文件链接：`[标题_精读本.html](file:///D:/...)`。
