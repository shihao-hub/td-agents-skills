# sh-agy-boost：深度思考增强调度器

> 版本 v1.0.0 ｜ 来源：Google Antigravity 斜杠命令 /boost。原版为服务端 "battle" 多 agent 编排系统（多方案对战、胜者会话合并，受 boost_command_disabled 管理员开关控制），编排器提示词不下发本地；本 skill 为本地多遍强化流水线复刻。

## 功能介绍

Antigravity 的 /boost：官方释义 "Invoke the Boost multi-agent orchestrator for complex tasks."。面向高难度、严谨性要求极高的任务，投入更多算力：深度思考、战略规划、多视角审查（对抗式审查）、严苛多阶段验证。

适用：复杂并发/死锁排查、核心算法实现、大规模底层重构等容错率极低的场景；普通提问难以一次性做对的疑难难题。

## 执行协议（本地多遍强化流水线）

### 1. 形式化与方案权衡（不许直接上手写）

- 把问题写清楚：输入/输出/不变量/失败模式。
- 并列 2-3 个候选方案：复杂度、风险、验证难度对比，说明取舍后择一。

### 2. 实现

按选定方案实现，边写边标注风险点。

### 3. 对抗式审查（视角切换）

以 hostile reviewer 视角攻击自己的产出，至少覆盖：边界条件与空值/极值；并发与竞态；资源泄漏与错误路径；安全隐患；与既有代码的契约冲突。
（环境有 adversarial-reviewer skill 时可委派它执行此步。）

### 4. 独立验证

重新跑测试/构建；构造针对原始问题的最小复现并确认已消除；不依赖实现过程中的旧输出。

### 5. 迭代收敛

审查/验证发现新问题 → 修复 → 回到第 3 步，直到一轮审查零新发现。

### 6. 交付报告

方案对比记录、审查发现清单（含已修复项）、验证证据（命令+输出）。

## 与原版的差异

- 原版为服务端多 agent 对战+胜者合并（battle 系统）；本版为单会话多遍流水线（方案对比→实现→对抗审查→独立验证循环）。
