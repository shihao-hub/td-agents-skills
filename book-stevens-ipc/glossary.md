# Glossary — UNP Vol 2 (Stevens)

**advisory locking** — fcntl record locking that only affects processes that explicitly check the lock (Ch 9)
**atomicity (PIPE_BUF)** — writes of ≤ PIPE_BUF bytes to a pipe/FIFO are never interleaved with other writers' (Ch 4)
**bandwidth program** — measures IPC throughput by sending increasing message sizes one-way (App A)
**bounded buffer** — fixed-size circular buffer coordinated by mutex + two counting semaphores (nempty/nstored) (Ch 7, 10)
**client-server FIFO pattern** — server reads well-known FIFO; each client gets a per-PID reply FIFO (Ch 4)
**condition variable** — pthreads object a thread waits on (pthread_cond_wait) until another signals a state change; always paired with a mutex and a while-rechecked predicate (Ch 7)
**counting semaphore** — semaphore whose value counts available units of a resource (buffers, items) (Ch 10)
**create-or-open race** — exclusive-create with O_CREAT|O_EXCL (or IPC_CREAT|IPC_EXCL), catch EEXIST, then reopen (Ch 2, 3, 11)
**descriptor passing** — sending an open fd through a Unix-domain socket / door descriptor array so the receiver operates on the same object (Ch 15)
**door** — Solaris server-side library call interface: door_call on a descriptor to a door server procedure (Ch 15)
**door_server_create** — replaces doors' default automatic thread creation with a custom server-thread pool (Ch 15)
**fork/exec/exit effects** — how each IPC object is inherited across fork, whether it survives exec, and what exit does (Ch 1, Fig 1.6)
**ftok** — makes a System V key_t from a pathname and id, combining st_dev and st_ino bits (Ch 3)
**full-duplex pipe** — SVR4/socketpair pipe where both ends read+write; really two half-duplex channels (Ch 4)
**ipc_perm** — System V permission structure (uid, gid, cuid, cgid, mode, key, seq) attached to every IPC object (Ch 3)
**identifier reuse** — System V IDs wrap after seq increments; old IDs are never immediately reused (Ch 3)
**kernel persistence** — IPC object lives until explicitly removed or system reboot: System V IPC, Posix MQ/sem/shm (Ch 1)
**latency program** — measures IPC round-trip time with ping-pong 1-byte messages (App A)
**locking versus waiting** — a mutex only excludes; a condition variable lets a thread wait efficiently for a predicate (Ch 7)
**mandatory locking** — record locking enforced by the kernel against all accesses; needs no-setgid-group-exec mount, rarely used (Ch 9)
**mq_notify** — registers the process (one at a time, no forks) to receive SIGEV_SIGNAL/SIGEV_NONE/a new thread when a Posix MQ becomes non-empty (Ch 5)
**msgsnd/msgrcv type multiplexing** — System V MQ selects by mtype: 0 first, >0 first of type, <0 first of type ≤ |type| (Ch 6)
**name space** — the rules for naming IPC objects: no-name (pipe/sem_init), pathname-like (Posix IPC, mq_open), key_t (System V) (Ch 1, 2)
**named semaphore** — sem_open'd, pathname-named, kernel-persistent semaphore vs memory-based sem_init in shared memory (Ch 10)
**O_NONBLOCK** — non-blocking semantics for FIFO open (returns ENXIO), empty reads (EAGAIN), and would-block writes (Ch 4)
**persistence taxonomy** — process / kernel / filesystem persistence classifies every IPC object's lifetime (Ch 1)
**PIPE_BUF** — minimum (≥512) atomic write size for pipes/FIFOs (Ch 4)
**popen/pclose** — stdio wrapper around pipe+fork+exec of `sh -c command` (Ch 4)
**process-shared attribute** — PTHREAD_PROCESS_SHARED on mutex/cond/rwlock attributes allows use in shared memory between processes (Ch 7, 8, 12)
**px_ipc_name** — portability helper that builds a valid Posix IPC name for the host OS (Ch 2)
**read-write lock** — lock allowing many concurrent readers or one writer; built from mutex + two condvars (Ch 8)
**record locking** — fcntl byte-range locks (F_SETLK/F_SETLKW/F_GETLK with struct flock) over file regions (Ch 9)
**rpcgen** — Sun RPC compiler that generates client stub, server skeleton, and XDR filters from a .x file (Ch 16)
**SEM_UNDO** — System V adjustment array undoes a process's semaphore operations at exit — with hazards if undos run in wrong order (Ch 11)
**sem_otime poll** — after EEXIST reopen, poll IPC_STAT until sem_otime != 0 proves the creator finished initializing (Ch 11)
**shared memory** — mmap MAP_SHARED / Posix shm_open / System V shmget region mapped into multiple processes; fastest IPC but needs external synchronization (Ch 12–14)
**single daemon instance** — open/write PID file then fcntl-write-lock it: a second copy's lock fails, so it exits (Ch 9)
**spurious wakeup** — cond_wait may return without a signal; hence the mandatory while-loop predicate recheck (Ch 7)
**stream vs message** — pipes/FIFOs are byte streams needing framing; message queues preserve boundaries natively (Ch 4, 5)
**System V semaphore sets** — semget creates a set operated atomically by semop arrays of sembuf operations (Ch 11)
**wrapper function** — Stevens's convention of wrapping a call with error check + errno → message + exit (Ch 1)
**XDR** — Sun RPC's External Data Representation: canonical encoding with filters per type, including discriminated unions (Ch 16)
**XID / duplicate-request cache** — RPC transaction id; a server-side cache of recent UDP replies gives at-most-once semantics (Ch 16)
