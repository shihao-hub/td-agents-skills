# 高考教辅/学霸知识手账信息图生成规范（sh-edu-infographic）

将学科笔记、理科定理、文科考点或流程知识转化为具有**「现代高品质教辅 / 小红书高考学霸知识手账」**质感的独立 HTML 单文件与卡片图解。

彻底摆脱暗黑 SaaS、大蓝紫渐变（`#6366F1` / `#8B5CF6`）与居中三卡片等生硬“AI 味”，采用白底明亮、色彩信息高度编码、图文并茂的印刷级教辅排版。

---

## 一、设计风格四大铁律

1. **白底明亮与双层外框**：
   * 页面底色为柔和灰蓝 `background: #e2e8f0;`，卡片主体为雪白纯净背景 `background: #ffffff;`。
   * 主卡片必须有明显的**天蓝色外描边**（`border: 2.5px solid #0284c7; border-radius: 20px;`），配合微弱弥散阴影。
   * 内部各个功能 Section 使用天蓝细边框（`border: 1.5px solid #38bdf8; border-radius: 14px;`）。

2. **学科特色 Header**：
   * 顶部采用 `#f0f9ff` 浅冰蓝微底框。
   * 左侧绘制与学科匹配的**手绘风线性 SVG 矢量图标**（如化学锥形烧瓶、物理滑块/天平、生物双螺旋、数学坐标系）。
   * 右上角配置 `rotate(5deg)` 轻微倾斜、楷体手写质感的热血标语（例如：“化学让世界更有规律！”、“格物致知，知行合一！”）。

3. **四阶语义色彩编码体系（拒绝蓝紫渐变）**：
   * 必须严格将逻辑状态与饱和胶囊颜色绑定，形成直觉对比：
     * **对比态 A（积极/上升/氧化/热/酸性）**：深红标签 `#ef4444` + 浅红微底 `#fff5f5` + 描边 `#f87171`。
     * **对比态 B（消极/下降/还原/冷/碱性）**：翠绿标签 `#10b981` + 浅绿微底 `#f0fdf4` + 描边 `#34d399`。
     * **过渡/产物/规律态**：暖黄标签 `#f59e0b` + 暖黄微底 `#fffbeb` + 描边 `#fcd34d`。
     * **介质/能量/电子转移**：典雅紫标签 `#7e22ce` + 紫色虚线网。

4. **实体化几何逻辑图解**：
   * 避免干瘪的文字列表，尽量将逻辑实体化为：
     * **水平双向流程链条**（实心圆角方块 + 箭头 `➜`）。
     * **几何变价/转换 N 型图**（四角对应物 + 对角线连线标注变化量）。
     * **双数轴映射模型**（上轴 vs 下轴，对角虚线标注反应趋势）。
     * **底部三列暖色口诀框**（带 `★ 核心规律总结` 徽章）。

## 二、标准化执行流程（SOP）

接到制作学科信息图或知识卡片需求时，按以下 5 步严格执行：

### 第 1 步：知识结构化解构
* 提取出：
  1. **主标题与副标题**（例：《氧化还原反应 · 核心图解》 / 《高中必修一核心卡》）。
  2. **核心对立/成对概念**（如：升 vs 降，酸 vs 碱，动量 vs 能量）。
  3. **模型示例方程式或几何图解**（具体化学式、物理模型或数学公式）。
  4. **记忆口诀/核心解题三定律**。

### 第 2 步：提取/复用设计组件
* 参考 `references/template-guide.md` 获取完整的 CSS 与 HTML 片段。
* 严禁引入外部 CDN 样式库（Tailwind / Bootstrap），一律编写精简高效的原生 Inline `<style>`，确保单个 HTML 文件离线双击即可完美渲染。

### 第 3 步：编写自包含 HTML 文件
* 页面统一采用宽度 `width: 980px`（适合高清晰度截图导出和移动端放大阅读）。
* 结构保持清晰层级：
  * Header（手绘 SVG + 标题 + 倾斜手写 Slogan）
  * Section 1：成对概念流线对比（左红右绿对称双列）
  * Section 2：典型反应模型几何图解（N 型图或力学分解图）
  * Section 3：双轴/多维规律数轴（双线平行对比图）
  * Section 4：金黄色卡片口诀与三定律总结

### 第 4 步：无头浏览器渲染验证（Windows 环境）
使用 Microsoft Edge 无头模式截取高质量图像并校验：
```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --disable-gpu --window-size=1040,1650 --screenshot="<out_png>" "<input_html>"
```
检查图片是否有白边或文字重叠，必要时裁剪到卡片底部像素。

### 第 5 步：交付产物
将生成的高清 `.html` 和 `.png` 路径呈现给用户，若有飞书群等推送需求，再配合 `lark-cli` 发送。
